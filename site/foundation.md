# 原四款基础 Skills

四个平台完整包都带齐以下四款基础 Skill 的正文、所需模板和参考。选择平台包后，不用再分别下载。它们按任务使用，不要求每单全部运行，也不等于已自动注册为四个原生技能对象。

| Skill | 大白话 | 什么时候用 |
|---|---|---|
| [dispatch-accept-verify](./generated/skills/dispatch-accept-verify) | 派出去的活要收回来 | 派单、接单、接回、退修与跟进 |
| [evidence-before-done](./generated/skills/evidence-before-done) | 交活前要有证据 | 打开实件、核版本、检查是否有权接受 |
| [beginner-ops-writing](./generated/skills/beginner-ops-writing) | 新手操作说明 | 必须由用户亲手操作时，说清位置、步骤与可见结果 |
| [ops-case-notes](./generated/skills/ops-case-notes) | 脱敏运营记录 | 查交接遗漏、参考真实弯路与未证明的边界 |

平台主 Skill 负责把这些方法接到对应宿主的采用和协作流程里。基础资料实际被谁读到，仍要在本单核实；首席读过不代表制作席和审核席自动读过。

[按平台取得完整包](./guide/start) · [查看技能之外的配置](./generated/configuration)

已经只使用原四款独立 Skills 的用户，可以继续沿用[原独立采用说明](https://github.com/dabingfy-dot/solo-to-team-skills/blob/main/SKILLS.zh.md)；新增完整包不会要求你替换已可用的对象。
