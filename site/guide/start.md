# 选一个平台，开始一份真实任务

一人成队是一套**由人统筹的多智能体协作系统（MAS）工具包**。它把派单、实际制作、独立审核、局部修改和交回连起来，运行在你已有的平台上。

你先定目标和使用范围，首席负责协调；需要时调用真实的制作与审核成员。16 席、6 群提供完整分工，但第一单不必全部启用。

## 1. 只下载自己使用的平台

每个完整包都带 **1 款平台协作 Skill ＋ 4 款完整基础 Skills**，以及角色、群规、模板、示例、建队台和接续工具。不用再找四份基础技能，也不用下载四个平台。

## 2. 分清包里的三种 ZIP

| 文件 | 用来做什么 | 怎么用 |
| --- | --- | --- |
| 下载得到的 `Solo-to-Team-…-bundle1.zip` | 装齐这一平台的全部交付资料 | **先解压**，打开 `START-HERE.md` |
| `platform/` 里的平台 Skill ZIP | 按平台方式采用主 Skill | 按对应指南上传、解压放入项目，或让目标 Bot 读取；四个平台方法不同 |
| `TASK-MATERIALS.zip` | 给这一单提供基础 Skills 和配置资料 | 作为**普通任务附件**，或解压后提供允许读取的实际目录；不放进技能安装框 |

::: tip 已有可用版本就复用
先核同名 Skill、实际版本和作用范围。同版已核可用，无需重复安装；更新不同版本前保留可恢复的旧内容。添加一个 Bot 或项目，不一定能隔离账号里的共享技能。
:::

## 3. 采用后，先收一份小成果

按平台指南采用主 Skill，再提供任务材料，使用包里的开工文本。让助手先说清它实际读到了什么、由谁制作、由谁审核、最后交到哪里。

接着完成[第一份小任务](/guide/first-task)：收到可打开的成果、同一版本的审核结果和修改记录。安装成功只是开始。
